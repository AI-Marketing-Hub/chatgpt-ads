# Platform and access

## Interpretation

Eligibility is a conjunction of market, advertiser, account, placement and feature access. Documentation about one does not establish the others. A billing threshold is a collection mechanism, not a campaign ceiling. Account identity must be established before interpreting visible settings.

This interpretation is methodological guidance, not an additional assertion about current platform availability.
