# Support

This is an independent community project. It has no service-level agreement,
managed account support or production-performance guarantee. The maintained
scope is the documented local source tree and synthetic checks.

When requesting help, include the release version, operating system, Python
version, exact command, and sanitized error output. Do not include credentials,
client data, account IDs, raw exports or browser captures. For environment
diagnostics, run `python3 scripts/doctor.py` and redact anything private before
sharing it.

Ask a [usage question](https://github.com/AI-Marketing-Hub/chatgpt-ads/issues/new?template=help.yml) or submit a [bug report](https://github.com/AI-Marketing-Hub/chatgpt-ads/issues/new?template=bug_report.yml). Security reports use the private route in SECURITY.md.
