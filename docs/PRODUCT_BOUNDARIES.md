# Product boundaries

The pack contains sourced knowledge, workflow instructions, local validators, simulated operating tests and host-specific browser procedures. It can assist an agent with authorized browser operations when the runtime exposes suitable tools. It does not supply an authenticated Ads API client or a universal browser controller.

Local authorization records are not identity authentication. Helper checks govern calls made through those helpers; an agent's direct browser calls are not sandboxed by a JSON record. Native account evidence is required before describing a workflow as account-verified.

No platform capability is inferred from the coverage matrix. Undocumented features, account gates, unavailable native exports and contradictory sources remain visible. No universal benchmarks or guaranteed performance are supplied.

Private data belongs outside the portable package. Pattern scans reduce accidental disclosure but do not prove anonymization or legal compliance. Public redistribution remains subject to the owner's license and source rights decisions.
