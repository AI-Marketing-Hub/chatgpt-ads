## Proposed release title and notes

**v0.3.0, public source-release candidate**

This release introduces a separately prepared public-source projection, a
verified portable archive path, beginner Codex and Claude walkthroughs,
support and contribution guidance, and OS capability documentation.

Linux deterministic checks are recorded locally. CI is configured for Linux
and Windows on Python 3.11 and 3.14, but it has not yet run remotely. Native
Windows guarded-filesystem workflows are unavailable because no native backend
is implemented; browser and account acceptance are also unverified. macOS is
not yet verified.

The project is independent and MIT-licensed for original material. It is not
an official OpenAI integration, and it does not establish advertiser account
access, billing, campaign approval, delivery or performance. The release
contains synthetic fixtures only, not credentials, client data, raw exports,
raw browser captures or private evidence.
