# Workflow output templates

Use the smallest relevant section. Replace placeholders only with supported facts or explicit assumptions. Omit nothing material to the decision. Unknown values stay `null` or “unknown”, with a resolution step. These are advisory outputs. Exact external actions use the companion versioned action-plan and receipt schemas. Private account outputs stay outside the shared package.
